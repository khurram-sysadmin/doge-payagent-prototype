# GitHub Upload Checklist

## Fastest Submission Path

1. Create or open the GitHub repository named `doge-payagent-prototype`.
2. Upload the root files and `docs` folder from this folder.
3. Commit to the `main` branch.
4. Enable GitHub Pages:
   - Settings
   - Pages
   - Deploy from a branch
   - Branch: `main`
   - Folder: `/root`
5. Use the GitHub repository URL for source submission.
6. Use the GitHub Pages URL as the demo link.

## Files To Upload After Each Local Update

```text
index.html
styles.css
app.js
README.md
.gitignore
docs/flow.md
docs/requirements.md
docs/github-upload.md
```

## Suggested Submission Summary

```text
Doge PayAgent turns natural-language requests into prepared restaurant bookings, food orders, and shopping carts. The AI prepares the action, the user approves the Mantle payment, and the backend verifies transaction proof before confirmation.
```
